The theme names the family but neither ships nor loads it. Load the font in your app, for example with `next/font`. If it is missing, nothing errors: the browser quietly falls back to the next family in the list.

## Sizes

Each step of the `text` scale, set in the font above. In this registry's own app the `text-*` utilities use these values; installing the theme does not change another app's type scale.
